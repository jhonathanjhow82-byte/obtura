# Obtura

Editor de fotos com IA, de fotógrafos para fotógrafos. Escolhe as melhores fotos, remove distrações com IA, revela RAW e roda offline. Mac e Windows.

Versão de teste: 14 dias grátis, sem cartão de crédito.

- **Windows** (64 bits): [Obtura-teste-Windows.zip](https://github.com/jhonathanjhow82-byte/obtura/releases/latest/download/Obtura-teste-Windows.zip)
